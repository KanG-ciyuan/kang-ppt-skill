# Task And Process Routing

Choose only the process depth needed for the requested outcome. User instructions override every default below.

| Task | Default process |
|---|---|
| major new or high-aesthetic deck | clarify the communication job, show three full-size directions, wait for selection, then author |
| ordinary new deck | clarify only consequential gaps, choose a suitable direction, then author |
| user template or reference deck | template is authoritative; inspect and edit inherited elements without mixing another style system |
| selective edit | lock scope, preserve unrelated slides, and edit directly |
| conversion or read-only question | route to `Presentations` without this standard unless the user requests the quality layer |

## Classification Signals

Treat the task as major when one or more of these materially applies:

- the deck is new and audience-facing;
- the user explicitly cares about visual quality or wants alternatives;
- the deck must persuade, sell, obtain approval, or represent a personal/public brand;
- the source material is large and needs a new narrative;
- a substantial redesign changes more than isolated slides.

Treat the task as direct when it has a supplied authoritative template, a tightly locked edit scope, a short operational purpose, or an explicit instruction to skip directions.

## Scope Lock

For selective work, state the slides or presentation aspects in scope. Do not restyle unrelated slides, replace the template, add new sections, or change claims without authorization.

## Delegation Boundary

This Skill selects the process and quality standard. `Presentations` owns PPTX implementation, template/master/layout mechanics, runtime dependencies, rendering, and file delivery.

The selected visual direction is task-local. Do not silently reuse it as Kang's permanent template.
